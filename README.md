# Blake Huebner

**Team Lead – Data & AI** · Berlin

I lead a data team and still build hands-on, covering data platforms, BI, applied ML and production LLM systems.
I'm currently at Flightright (Allright Group), a legal-tech company for EU flight compensation claims. Before that I spent four years in fraud and risk data science.

## What I work on

- **Data platforms:** modern ELT stacks, designed and built from scratch
- **Applied ML:** predictive models shipped as production microservices
- **LLM systems:** gateways, agents, evaluation harnesses, document AI / OCR
- **BI:** production dashboards that business teams use every day
- **Leadership:** people management, product ownership, turning stakeholder needs into technical roadmaps

## Selected work

- **Data platform from scratch:** company-wide ELT platform on Snowflake, dbt, Airbyte, Airflow, Terraform, Docker, AWS and GitLab CI/CD.
- **Legal claim outcome model:** LightGBM win-probability model that combines internal claims data with weather, event and aircraft-history data. It runs as a Dockerized FastAPI service on AWS Lambda and informs case intake decisions.
- **LLM gateway:** internal middleware that routes, governs and standardizes LLM access across teams for document parsing, OCR pipelines and summarization.
- **Disruption monitoring agent:** scrapes aviation news and uses an LLM to classify events for EU261/UK261 claimability. It has a labeled evaluation harness, and I A/B-tested 12+ prompt variants on it.
- **Operating-entity classification:** tiered rule-based waterfall that identifies the operating airline entity for legal proceedings, with ~98% cross-validated accuracy on 6,000+ labeled records.
- **Multilingual document processing:** benchmarked open-source OCR models (Surya, LightOnOCR, PaddleOCR, Nemotron OCR) and built PDF extraction pipelines with pdfplumber + LLMs. I'm now designing a serverless document-cleaning service on Lambda + Step Functions.
- **tableau-ai-tools:** a Python MCP server and CLI, with safety gates, for AI-assisted Tableau workbook editing.
- **BI:** production Tableau dashboards for Legal, Ops, Product, Marketing and Finance.
